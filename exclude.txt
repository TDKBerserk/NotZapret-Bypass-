# Ручной чёрный список серверов.
# Формат: ip:port на строку (можно с комментарием после #).
# Как получить ip:port: открой details.json из последнего запуска и найди
# там нужный конфиг по стране/пингу — там есть готовое поле "ip" и "port".
#
# Сюда заносишь конфиги, которые вручную пропинговал в Happ и они не
# работают. При каждой пересборке такие ip:port выкидываются ДО проверки
# и никогда не попадут в whitelist/blacklist повторно, даже если источник
# продолжает их отдавать под новым UUID/тегом — потому что привязка идёт
# к серверу (ip:port), а не к конкретной ссылке.
#
# Пример:
# 45.12.34.56:443   # не подключается в Happ, RST сразу
